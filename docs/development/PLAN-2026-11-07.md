# Plan: real boot, usable editions, themes and local AI (owner decisions 2026-11-07)

Decisions recorded from the owner's answers to Claude. They guide the next
releases; each item still needs implementation and real evidence.

## Order of delivery

1. **Real boot first** — UEFI live USB ISO for physical PCs, then an installer.
2. Desktop look: Hyprland, themes, official INT ASCII banner, first-boot setup.
3. Local AI "super command".

## Hardware

Laptops and desktops, Intel and AMD first (CPU and integrated/AMD graphics,
common Wi-Fi/Ethernet firmware). NVIDIA added in later releases. The owner's
own Windows PC is not to be modified (VM only); real tests use whole PCs
booted from USB.

## Installer and first boot

- Live USB to try without changes, then install on a whole disk (no dual boot
  required for now).
- Installer and first-boot assistant in **French and English**, with keyboard
  layout choice (Swiss/French AZERTY offered).
- First-boot choices: edition profile, desktop engine, theme presets (at least
  dark, blue, pink, anime), application presets, optional local AI model size.

## Editions

- **INT-OS** (minimal): choice between **Sway** (light) and **Hyprland**,
  restricted Hyprland configuration when resources are low.
- **OS-INT** (cyber/opsec, may use more resources, as complete as possible):
  **Hyprland**. Default groups: **cyber/network tools** and **opsec/privacy**
  (full-disk encryption, MAC randomisation, WireGuard, metadata cleaning).
  Web browser, development tools and other groups are **chosen by the user**
  at setup. Gaming is low priority.

## Look

Strongly resembling riced Arch/Hyprland setups (references were in
`themeExemple/`): translucent/blurred terminals, rounded borders, fetch-style
system info with a large **INT ASCII** logo shown automatically, top bar with
system modules, dashboard widgets. 100% customisable but easy: colours, bar
modules/tabs, custom ASCII, wallpaper. Anime theme wallpapers only under an
explicit free licence (CC0/CC-BY, source recorded); users can add their own.

## Local AI "super command"

- Model size chosen at install (small/medium/none, guided by detected RAM).
- Integrated as a system agent, not a chat app: it maps a request to system
  actions (themes, dashboards, files, package install, integrity/malware
  checks) and produces almost no conversational text.
- **Without confirmation:** read-only queries and theme/appearance changes.
  **Always confirmed:** file creation/deletion, package installation,
  privileged scans and any system change.

## Work split

- **Claude:** ISO, boot on real hardware, installer.
- **Codex:** desktop (Hyprland/Sway choice), themes, ASCII, first-boot look;
  then finish the signed package feed.
- Local AI: whoever finishes first, announced in `COORDINATION.md`.
